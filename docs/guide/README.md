# Style guide

Burin Map draws seven kinds of thing. All share one `style` object and the same
spacing/ink model from [00-model.md](00-model.md); each page below gives the
**full parameter table** for that one, plus close-up comparisons.

**On the web app:** open **Docs** (`/docs`) for this guide with the comparisons
as zoomable SVG, plus an overview of the project and a page of whole examples.

## Draw styles

| Page | `draw` / block | What it is |
|------|------|------------|
| [00-model.md](00-model.md) | — | Shared model: tone, spacing axis, ink axis, order of rules |
| [land-lines.md](land-lines.md) | land batch, `draw: "lines"` (default) | Streamlines along or across the terrain, dashed by light/shadow |
| [land-dots.md](land-dots.md) | land batch, `draw: "dots"` | Stippling, denser in shadow and on steep ground |
| [water-lines.md](water-lines.md) | `burin.water("lines", …)` | Lines on water, spaced by distance from shore |
| [water-ripples.md](water-ripples.md) | `burin.water("ripples", …)` | Broken, swelling rows — Olaus Magnus' sea |
| [water-dots.md](water-dots.md) | `burin.water("dots", …)` | Stippled water, denser near the coast |
| [shoreline.md](shoreline.md) | `burin.shore(…)` | The coast itself, plus optional lines out to sea |
| [fills.md](fills.md) | land/sea batch, `draw: "fill"` | Flat colour bands by height or depth |

Full parameter reference (every group, every default): [SYNTAX.md](../../SYNTAX.md).

## Whole documents

The pages above take one parameter at a time. To see what they add up to, read
the documents in [`presets/`](../../presets/) — above all
[`engraved-sea.js`](../../presets/engraved-sea.js) (hatched hills, a doubled
coast, and an open sea of currents waving in step), `sea-depth.js`,
`layer-tints.js`, `contour-belts.js`, `downhill.js` and `scripted-hills.js`.
The web docs (`/docs/examples`) show each one whole, with a zoomable vector
detail and the role of every pass.

## Quick recipes

```js
// Contour lines only (no dashes)
burin.batch({ angle: 0, style: { dash_light: 1, dash_dark: 1 } });

// Mechanical half-ink in light, solid in shadow
burin.batch({ angle: 0, style: { dash_light: 0.5, dash_dark: 1 } });

// Stippled land
burin.batch({ angle: 0, draw: "dots", style: {} });

// Lines on water, tight near the shore
burin.water("lines", { follow: "shore", angle: 0, style: {} });

// A clean double shoreline
burin.shore({ lines: 2, style: { space_light: 4 } });
```

## For tools and agents

- Parameter names, defaults, help text: `Style::PARAMS` in `crates/burin-map-core/src/style.rs`
- Ink along a line: `crates/burin-map-core/src/dashes.rs`
- Land spacing field: `crates/burin-map-core/src/fields.rs`
- Water (lines, ripples, dots, shoreline): `crates/burin-map-core/src/water.rs`
- Images in `img/` are generated by rendering the same six-by-four-km coastal
  area (`37.73811,-122.36351`) with a few parameters changed, so differences are
  side by side rather than described.
